# Modifications in TransDub Studio

TransDub Studio is a customized build based on [pyVideoTrans](https://github.com/jianchang512/pyvideotrans).

Notable downstream changes include:

- macOS application wrapper and local deployment improvements.
- Custom macOS-style application icon.
- Single-instance launch behavior and no-terminal background startup.
- DeepSeek subtitle translation tuning for better whole-context translation.
- F5-TTS local voice-cloning workflow fixes, including safer reference-audio selection and English-leak detection.
- Dubbing reliability improvements to avoid silently producing broken output when synthesis fails.
- Versioned `.tdproj` v3 state with stable dubbing-unit IDs, candidate history, content-addressed quality reports, and legacy-project migration.
- An experimental local-first joint dubbing planner that evaluates semantic grouping, Chinese wording, duration, synthesis, and quality feedback in one loop, with an optional whole-turn DeepSeek candidate backend, strict local validation, response caching, and deterministic offline fallback.
- A non-blocking, default-on Dubbing Studio smart-planning preview that uses DeepSeek when configured, falls back locally, exposes per-segment timing diagnostics, and never automatically replaces subtitles or audio.
- Deferred whole-track waveform and dubbed-preview construction for long videos, keeping the editor responsive while retaining immediate timeline and per-segment controls.
- Explicit per-segment A/B synthesis and listening for saved plans, reusing the current TTS backend without retranslation or changing the production audio selection.
- A one-click smart-dubbing default flow: after choosing a video and target language, recognition, translation, joint semantic/timing orchestration, TTS, quality checks, alignment, and rendering run without routine proofreading pauses. Engine controls remain available under Advanced settings, and persisted smart queues provide interruption-safe resume.
- Long-video F5-TTS hardening: source-timeline reference extraction, Apple Silicon low-memory lifecycle management, high-risk preflight samples, batch plus per-clip language gates, service recovery, cache-preserving retries, and ASR-verified Chinese resume anchors matched by speaker.
- Content-addressed incremental quality orchestration: every generated clip is tied to its audio/text/model/rules signature, checked in disposable MLX or CPU large-v3-turbo workers, persisted into `.tdproj` quality reports, and reused only while that exact signature remains valid. Long videos no longer require a full-track ASR pass after every resume.
- Automatic resource governance for unified-memory Macs: F5 and MLX never share Metal residency; live memory, swap, and normalized load pressure automatically shrink reference cutting, source separation, and strong-validator concurrency or batch sizes without lowering model quality; speaker/reference analysis reuses cached readbacks and MFCC features.
- Process-internal reference slicing for seekable audio avoids launching FFmpeg for every cloned segment, while preserving an automatic FFmpeg fallback for unusual codecs.
- Unified `.tdproj` checkpoints for smart planning, stage journals, and clip-level quality state; the progress page and recent-task list can recover completion, failure, or interruption after an app restart.
- Failure-contained quality review: ordinary F5 content failures preserve every passed clip, open a focused Dubbing Studio repair queue, support failed-only filtering and retry, and block export only while unresolved clips remain. Infrastructure/model failures still stop immediately.
- Project-local performance diagnostics with stage durations, process-tree peak memory/CPU, minimum available memory, peak pressure, TTS real-time factor, cache hits, and quality totals, sampled at low frequency to avoid adding heat.
- Zero-tolerance unexpected-Latin validation for Chinese output and per-speaker Chinese bootstrap anchors: clean preflight clips become the conditioning reference for the remaining run, sharply reducing F5's tendency to continue speaking from an English source reference. Quality and synthesis cache versions are bumped so earlier permissive passes cannot leak into new runs.
- Per-speaker reference banks retain up to three ASR-verified anchors, select question/exclamation/statement-compatible conditioning, and rotate anchors across retries. Chinese coverage checks now also isolate truncated, mismatched, or adjacent-clip spillover instead of treating all-Chinese readback as automatically valid.
- Legacy-project quality migration in Dubbing Studio: a one-click disposable strong-ASR audit preserves passed clips, marks only mixed/truncated/spilled/repeated clips for repair, persists exact content signatures, restores the failed-only queue after reopen, and blocks export when current audio/text/rules are not covered.
- F5 local-service cache isolation: the launcher now overrides app-level Hugging Face cache variables so the bundled Vocos/F5 weights remain discoverable in offline mode. Cold-start failures extract a concise cause from the new service log instead of reporting only a generic startup error.
- Failure-safe dubbing checkpoints: every successfully synthesized candidate is copied into the `.tdproj` before a later clip, service restart, or quality stage can fail. Resume restores only candidates with the same text, voice, timing, model, NFE, and seed signature; automatic repair writes to a staged file and never deletes the last usable clip first.
- Memory-safe F5 quality orchestration: strong validation reuses one disposable ASR worker for the pending set, waits for unified-memory headroom before restarting F5, defers ordinary repair failures to Studio, and opens a synthesis circuit after an infrastructure failure instead of retrying the service hundreds of times.
- macOS lifecycle hardening: local and packaged launchers now `exec` the virtual-environment Python directly, while the GUI owns launcher-lock and F5 cleanup. A lightweight Qt signal heartbeat ensures normal quit signals are processed and prevents detached GUI/model workers from surviving app exit.
- Slot-aware F5 synthesis for long videos: global slow-rate preferences are preserved when the timeline has room, but oversized Chinese lines synthesize close to their planned slot before final alignment. Per-clip and cold-start heartbeats expose elapsed time, while serial MPS blocks release unused cache and stay below physical unified-memory pressure instead of pushing 16 GB Macs into multi-gigabyte swap.
- Backend-neutral synthesis supervision: preflight always includes the predicted highest-cost line; every clip receives one duration-admission decision, a rolling-median watchdog, and a run-relative memory/swap gate. A stalled backend is recycled once at clip scope, successful prefixes remain atomically resumable, and supervisor diagnostics follow the durable project checkpoint.
- Context-preserving local repair: failed Chinese clips borrow up to three verified full-video anchors ranked by explicit speaker identity or cached source-voice similarity, rotate them across retries, synthesize into a staged file, and replace the last playable clip only after strong-ASR acceptance. Incremental sidecars merge instead of erasing unrelated failures, live repair state survives restart, and Studio shows current line, batch progress, preserved-audio failures, and an unambiguous Next state.
- Source-safe translation orchestration: source-aligned translations are stored separately from resegmented final subtitles; every planned Chinese segment must preserve complete, ordered `source_unit_ids`; checkpoint fingerprints invalidate stale mappings; and deterministic number/unit checks stop high-confidence semantic drift before any expensive TTS work begins.
- Adaptive translation batch recovery: malformed LLM SRT batches are rejected before caching, recursively split and retried at smaller sizes, then rebuilt into a validated resumable parent cache. Unsafe count mismatches can no longer be repaired by timestamp-only filling, and semantic drift is now rejected immediately after translation instead of after long-running smart planning.
- Beginner-first Dubbing Studio: the default view now centers on video, original/Chinese A-B playback, issue repair, and export; hundreds of subtitle cards, waveforms, timing tools, and experimental planning controls are created only after expanding Advanced editing. Per-line listening is anchored to the video clock, while long videos can build a cached continuous synchronized preview on demand using a linear disk-backed mixer instead of repeatedly copying the whole track.
- Beginner-first delivery choice: Simple Mode now exposes a first-class “original audio + bilingual subtitles” output. It explicitly renders English-above-Chinese hard subtitles, skips TTS and its quality gate, keeps the source audio, and does not accidentally fall back to subtitle-extraction mode when the selected voice is `No`.
- Output-path reliability: progress cards now keep the retry root and each video’s real output subfolder separately, so “Open folder” lands on the finished video rather than its often-empty-looking `_video_out` parent. Recent tasks persist the default output root as well, allowing the result to be found after a restart.
- Bilibili-oriented bilingual hard-subtitle preset: English is slightly smaller and neutral, Chinese is larger and bold, both retain a high-contrast outline and safe bottom margin, while the second bilingual line now actually honors its separately selected font.
